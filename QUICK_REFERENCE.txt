🎯 FEATURES AT A GLANCE
════════════════════════════════════════════════════════════════════════════

TIMER CONTROLS (During Session)
  ⏱️  Start/Pause:    Tap "Start" or "Pause"
  ⏭️  Next Phase:     Tap "Next Phase" or swipe forward
  ⏮️  Previous:       Tap "Back" or swipe back
  ⌛ Adjust Time:     Tap duration, use +/- buttons
  🔧 Edit Drill:      Tap "Edit" (pauses session)
  📋 Resume:          "Resume" button after edit

GRADING DURING SESSION
  📊 Enable:          Tap 📊 button in header (Grading ON)
  👤 Select Student:  Tap student name in roster
  ⭐ Score Skill:     Tap skill → select score (1-5)
  💬 Add Note:        Tap again, add comment
  👁️  View Class:     "View Class" shows all students + scores
  💾 Auto-Save:       All grades saved to device

COACH SELECTION
  🧑 Add Coach:       Planner → Select Coach → Choose from 8
  🎨 Color Coding:    Each coach has distinct color
  🎭 Animations:      Coach slides in/out with phases
  🗣️  Display Names:  Customizable in Settings

TIMER PHASES & COLORS
  🟡 Amber = Demo        (Coach demonstrates technique)
  🔴 Red = Work          (Students practice)
  🔵 Blue = Swap/Rest    (Changeover or recovery)
  🟢 Green = Break       (Water, setup next drill)
  🔊 Klaxon = Warning    (10 seconds remaining on work phase)

AUDIO SYSTEM
  🔔 Bell Setup:        Settings → Timer & Class
  🎵 Mix Mode:          Bell plays with Spotify (default)
  🎚️  Volume:            0-100% slider in Settings
  🔊 Test Bell:         "Test Bell" button (verify volume)
  📳 Silent Check:       Ensure device not in silent mode

KEYBOARD SHORTCUTS (Most Devices)
  ESC:        Close game / Pause on timer
  ENTER:      Start session / Confirm
  SPACE:      Play/Pause
  ←/→:        Previous/Next phase
  ↑/↓:        Adjust time
  G:          Toggle Grading mode
  T:          Open Timer
  P:          Open Planner
  S:          Open Settings

AFTER SESSION (Finish Screen)
  📝 Coach Notes:       Add reflection (optional)
  💾 Save Session:      Auto-saved, also "Save & End"
  📊 View Grades:       Summary card with all student scores
  📤 Export:            Share session as .fkbc.json
  🔄 New Session:       Start another class
  📱 View History:      See all past sessions

🐛 QUICK TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Bell won't play:
  ✓ Check device volume (not in silent mode)
  ✓ Settings → Bell volume (increase if low)
  ✓ Tap "Test Bell" button to verify
  ✓ Try "Bell Priority" mode instead of "Mix"

Spotify keeps pausing:
  ✓ Switch to "Mix" mode (music should continue)
  ✓ Make sure FKBC is active/visible
  ✓ Check Spotify app settings
  ✓ Restart both FKBC and Spotify

Grades not saving:
  ✓ Enable Grading mode (📊 button)
  ✓ Check IndexedDB (Browser DevTools → Application)
  ✓ Export grades before closing app
  ✓ Restart app and retry

Game won't load:
  ✓ Check internet connection
  ✓ Wait 5-10 seconds (game may be loading)
  ✓ Reload page and try again
  ✓ Clear browser cache (Settings → Clear Cache)
  ✓ Try different browser

Timer not syncing with music:
  ✓ Timer is local (device), not synced to Spotify
  ✓ Count down matches Spotify time
  ✓ If off: press "Adjust Time" to correct
  ✓ Use separate timer for Spotify time

📊 GRADING SCALE QUICK REFERENCE
════════════════════════════════════════════════════════════════════════════

Default 1-5 Scale:
  1 = Needs Work       (Beginner, requires coaching)
  2 = Developing       (Some proficiency, inconsistent)
  3 = Proficient       (Solid basics, ready to progress)
  4 = Advanced         (Excellent technique, minor refinements)
  5 = Expert           (Perfect execution, can teach others)

Skills Tracked (10 Categories):
  • Stance & Balance    - Feet position, weight distribution
  • Footwork            - Movement, distance control
  • Jab                 - Speed, accuracy, power
  • Cross               - Follow-through, power transfer
  • Hooks               - Arc, timing, angle
  • Kicks               - Technique, balance, power
  • Defense             - Guard, head movement, blocks
  • Takedowns           - Technique, control, safety
  • Cardio              - Breathing, pace management
  • Mental Game         - Focus, composure, strategy

💾 DATA BACKUP & RECOVERY
════════════════════════════════════════════════════════════════════════════

Before Device Change:
  1. Settings → App & Data
  2. Tap "Export All Data"
  3. Email or save .json file to cloud
  4. Install app on new device
  5. Settings → App & Data → "Import from Backup"
  6. Select saved .json file
  7. All data restored!

If App Crashes:
  1. Reopen app
  2. "Recover Session" card appears
  3. Tap to resume from where you left off
  4. All grades saved automatically

Regular Backups:
  → Export at end of each week
  → Store in cloud (Google Drive, Dropbox, etc.)
  → Keep 2-3 recent backups
