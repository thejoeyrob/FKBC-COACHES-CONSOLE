🎮 ABOUT THE FIGHT GAME
═══════════════════════════════════════════════════════════════════════════════

What is it?
  A Phaser 3 TypeScript arcade fighter featuring Joe from FKBC, with training
  mode for practicing combos and an arcade mode for fun between sessions.

Is it required?
  No! The console works perfectly without it. It's a bonus sideload.

Does it slow down the app?
  No! The game only loads when you tap "LAUNCH FIGHT ARCADE" button, and runs
  in a separate iframe. The console stays fast.

Can I customize it?
  Yes! It's built from FKBC-App-Store-Repo (Phaser 3 TypeScript). You can:
  - Add more characters
  - Create new stages
  - Add game modes
  - Customize controls

Want to include it?
  1. Clone FKBC-App-Store-Repo
  2. Build: npm install && npm run build
  3. Copy dist/ to fight-game/
  4. Run verify-elite-build.sh again
  → More info: docs/MOVE_LIST.md (complete move list)

❓ FAQ
═══════════════════════════════════════════════════════════════════════════════

Q: How do I install this on my iPad?
A: Open the HTTPS link in Safari, tap Share → Add to Home Screen.
   → More: README_ELITE.md section "Browser Support"

Q: Does the bell work over Spotify?
A: Yes! Uses Web Audio API (doesn't pause music). Test before class.
   → More: README_ELITE.md section "Audio System"

Q: Can I grade my students?
A: Yes! Tap 📊 button to enable grading mode. Score skills during session.
   → More: README_ELITE.md section "Grading & Analytics"

Q: Can I customize the app?
A: Yes! Coaches, techniques, colors, timing, all customizable.
   → More: INTEGRATION_GUIDE.md section "Customization"

Q: What if I don't have internet?
A: App works fully offline (after first load). Service worker caches everything.
   → More: README_ELITE.md section "Offline Usage"

Q: How do I deploy this?
A: Push to GitHub, enable GitHub Pages. That's it! No build step.
   → More: INTEGRATION_GUIDE.md section "Deployment"

Q: Can I export my grades?
A: Yes! CSV, JSON, or PDF. Perfect for records & sharing.
   → More: INTEGRATION_GUIDE.md section "Grading & Analytics"

Q: Where's the game?
A: Tap 🎮 "LAUNCH FIGHT ARCADE" button (or find in welcome screen).
   → More: README_ELITE.md section "Fight Arcade"
