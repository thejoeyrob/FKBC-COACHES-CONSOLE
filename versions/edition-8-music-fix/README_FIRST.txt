FKBC COACH CONSOLE — EDITION 8
Complete flat PWA • 10 September 2026

GET THE APP RUNNING
1. Extract the ZIP.
2. Upload ALL extracted files together to the root of your GitHub Pages repository. Replace the previous app files as a complete set. No build commands or cloud account are needed.
3. Open your GitHub Pages HTTPS address. If an update banner appears, choose Update now before starting a lesson.
4. Open once online and wait for Ready offline before teaching without a connection.

INSTALL ON IPAD / IPHONE
Open the hosted address in Safari. Share → Add to Home Screen → Open as Web App (if shown) → Add.
On Android, use Chrome → menu → Install app / Add to Home screen.
This is a hosted PWA: opening index.html directly in the Files app is not an installation method.

ON THE FLOOR
Choose a template or build a blank session. Assign the lead coach and any section coaches. A section may be a single timed block or named work/rest rounds. Add coaching cues and equipment.
Fit to time adjusts flexible blocks while preserving rounds and locked timings. Totals include rests and changeovers; a programmed final rest prevents an extra automatic changeover.
Review the team briefing. Start your music, return to FKBC, test the bell through your actual speaker, then start the session.
Pause, move between work/rest phases, add or remove 30 seconds, or edit the current drill. Editing pauses the session; Resume continues it. End Session saves a record and a coach reflection in History.

MUSIC AND BELLS
Mix with music requests the browser's ambient audio session. Bell / bleep sounds and the 10-second warning use Web Audio scheduling.
Spotify mixing, Bluetooth routing, silent-mode behaviour and background audio still depend on the device/browser. They have not been physically verified on your iPad. If music interrupts the bell, use a separate device for music. Keep FKBC visible. The recommended default pauses the lesson when leaving the app or locking the screen.

COACH HANDOVER
Share lesson exports the complete plan, including rounds, coaches and notes, as a .fkbc.json file. Another coach imports it into Sessions. View team brief also provides a printable / downloadable briefing.
Plans are saved per device. Sharing creates a copy; edits do not sync automatically. Live chat and account-based cloud sync are not included in this release.

KEEP YOUR PLANS
Settings → App & data → Export all data creates a backup. Import lesson / backup restores it. Back up before replacing an older installation or changing hosting address.
The app attempts to migrate the previous fkbc_ultimate draft, saved sessions and rounds when using the same browser and hosting origin. Original keys are preserved. Data on another address, browser or device needs an exported file.
An interrupted session offers Recover session and resumes paused.

ARTWORK
Eight coach identities are included: Joe, Jack, Paul, Big John, Justin, Gracie, John and Eden, with portraits for planning and full-body timer panels. The John and Eden full-body illustrations use charcoal backgrounds to preserve clean rendering; these two are not transparent cutouts. Display names can be changed in Coaches.
