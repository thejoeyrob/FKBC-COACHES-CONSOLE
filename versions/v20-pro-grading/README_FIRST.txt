FKBC Lesson Planner v20 PRO

GitHub Pages / static hosting:
1. Extract this ZIP.
2. Upload EVERY file in this folder to the same web root/repository folder. Do not upload the ZIP itself.
3. Keep index.html, manifest.webmanifest, sw.js, the coach PNGs, sound files and icons together.
4. Open the HTTPS page in Safari/Chrome and choose Add to Home Screen / Install App.

This build is intentionally flat for GitHub Pages.
