How the planner works

Sections: pick a type (Warm Up, Technique, Pad Work, Sparring, Fitness, Cool Down), give it a description and a coach.

Time: one block of minutes. Rounds: number of rounds, round length and rest. Pad swap (Technique / Pad Work / Partner Work): rounds each, demo time, work time and swap-over time.

Swap after every round ticked: demo → partner A works → swap → partner B works, then the next technique (e.g. 1:00 + 2:00 + 0:30 + 2:00 = 5:30 each). Unticked: A does every round with a new technique each time, then swap, then B does them all.

Techniques: optionally list one per line so the timer shows the technique name each round.

Fit to time adjusts blocks and round counts to a target length. Brief gives the team a timed running order to copy or share.

Timer: the coach slides in for their part and out at the end. Bell on every change, klaxon at 10 seconds, beeps for the last 3.
